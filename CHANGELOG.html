更新日志 (Changelog)

项目: ccr-switch · 遵循 Keep a Changelog 标准 · 生成时间: 2026-06-07

v1.2.0 — 2026-06-07

Added

  • MiniMax M3 模型支持（/model mm,m3），替换原有的 M2.7
  • M3 默认启用 extended thinking（budget_tokens=32000），在请求中自动注入 thinking: { type: "enabled", budget_tokens: 32000 }

Changed

  • MiniMax provider 模型映射从 m2.7→MiniMax-M2.7 改为 m3→MiniMax-M3
  • config.json 和 config.example.json 中所有 m2.7 引用更新为 m3
  • README.md 和 SKILL.md 文档更新，反映 M3 替换

Removed

  • 移除 MiniMax M2.7 模型支持

v1.1.0 — 2026-05-30

Fixed

  • 修复响应体修改后 content-length 重新计算问题
  • 修复 Chinese comma（全角逗号）自动归一化到 ASCII comma

Added

  • 新增 /v1/models 端点，支持 /model 命令验证

v1.0.0 — 2026-05-26

Added

  • 初始版本，独立 Node.js proxy（零外部依赖）替代原有 CCR 架构
  • DeepSeek V4 Pro / V4 Flash + MiniMax M2.7 多 provider 路由
  • System role 提升到 top-level 的兼容修复
  • adaptive→enabled thinking type 转换
